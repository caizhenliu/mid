# mid

## 稿件附件

作者儲存草稿時至少要有一個附件（編輯既有草稿時，可保留現有附件或新增附件），最多 5 個文件（PDF、DOC、DOCX、ODT、RTF、TXT），每個檔案上限為 20 MB。附件保存在應用程式目錄下的 `uploads/`，下載時會使用原始檔名；請確保執行服務的帳號可寫入此目錄，並將它納入備份與存取管理。FastAPI 啟動時會建立附件資料表。

## 帳號登入

第一次啟動時，應用程式會自動建立 `users` 資料表，並在既有 `articles` 表新增 `author_user_id` 欄位及索引；也會將既有帳號與顯示名稱欄位改為不限制長度的文字欄位。不需要手動新增資料表。`schema.sql` 也包含相同結構，可供手動初始化使用。

帳號與密碼可使用任意字元及長度，但不可留空；帳號會依原樣辨識，包含大小寫及前後空格。系統會直接使用帳號名稱作為顯示名稱。一般註冊建立作者帳號。註冊編輯帳號需先設定註冊碼，並提供給受信任的編輯；例如在 Windows PowerShell 啟動服務前設定：

```powershell
$env:EDITOR_REGISTRATION_CODE = "請換成只有管理者知道的長隨機字串"
$env:SESSION_SECRET = "請換成長隨機字串"
uvicorn main:app --reload
```

`SESSION_SECRET` 應固定設定，以便服務重啟或多個工作程序共用登入狀態。若未設定，程式會產生暫時的隨機值，服務重啟後所有人都需要重新登入。既有稿件不會自動綁定新帳號；既有稿件仍可在編輯專區查看，但作者帳號只會看到該帳號建立的新稿件。

登入憑證會保存在各分頁的 `sessionStorage`，因此同一瀏覽器的不同分頁可以使用不同帳號；刷新目前分頁會保留該分頁的登入狀態。更新此登入方式後，請在各分頁重新登入一次。
